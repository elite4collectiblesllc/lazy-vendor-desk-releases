# Elite 4 Lazy Vendor Desk: release files

The files the Elite 4 Lazy Vendor Desk apps update themselves from. There's no source code here.

- **latest.json**: the newest version of each app, where its file is, and the file's SHA-256 (each app checks the
  file against it before using it), plus the oldest version each app may be to keep saving to a shop's cloud data.
- **Releases**: the files themselves. `desktop-v…` has the Windows program (one .exe); `phone-v…` has the Android
  app (.apk) and the live update for it (`lvd-web-….zip`).

To start using the program, download the newest Windows program from **Releases**, put it in a folder of its own
and open it. From then on, it and the phone app update themselves.
